# منصة بصمة كتاب

موقع عربي متعدد الصفحات، باتجاه RTL، مبني باستخدام HTML وCSS وJavaScript دون إطار عمل أو خدمات اشتراك.

## صفحات الموقع
- `index.html`: الصفحة الرئيسية.
- `services.html`: دليل الخدمات وتصفيتها حسب المجال.
- `request.html`: نموذج طلب موجه متعدد الخطوات.
- `contact.html`: قنوات التواصل.

## الوظائف
- 11 خدمة ضمن أربعة مجالات.
- نموذج طلب يدعم اختيار خدمة واحدة أو عدة خدمات، وجمع وصف مستقل لكل خدمة.
- مراجعة بيانات الطلب قبل فتح رسالة واتساب.
- روابط اتصال وبريد وحسابات المنصة.
- PWA وملفات تشغيل أساسية دون اتصال بعد أول زيارة عبر HTTPS.

## آلية الطلب وحدود البيانات
النموذج أداة تنظيم وجمع تفاصيل، وليس نموذج ذكاء اصطناعي أو خدمة خلفية. لا تُحفظ الطلبات في قاعدة بيانات ولا تُرفع الملفات إلى الموقع. بعد مراجعة البيانات، يفتح النموذج رسالة واتساب جاهزة على الرقم `+967782021367`، ويجب على العميل الضغط على إرسال داخل واتساب وإرفاق ملفاته في المحادثة.

## تشغيل محلي
يمكن تشغيل الموقع عبر خادم محلي:
```bash
python -m http.server 8000
```

## النشر
يُستخدم GitHub Pages عبر ملف سير العمل `.github/workflows/deploy.yml`. النشر يتم تلقائياً عند التحديث على الفرع `main`.
