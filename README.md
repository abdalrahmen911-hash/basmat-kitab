# منصة بصمة كتاب — ملفات الموقع

نسخة موقع عربي RTL متجاوبة ومصممة للهاتف أولاً، مبنية بـ HTML وCSS وJavaScript خالص، دون إطار عمل أو مكتبات أو خدمات اشتراك.

## تشغيل محلي

يمكن فتح `index.html` مباشرة في المتصفح لمعاينة الواجهة الأساسية. لتفعيل تجربة PWA والخدمة العاملة دون اتصال، شغّل المجلد عبر خادم محلي أو استضفه عبر HTTPS. مثال:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الوظائف المضمنة

- الهوية والتعريف الكامل بالمنصة ورسالتها ورؤيتها وأهدافها.
- الخدمات الإحدى عشرة ضمن أربعة أقسام، مع تصفية وعرض تفصيلي لكل خدمة.
- مساعد تفاعلي محلي يجمع تفاصيل كل خدمة بأسئلة متتابعة، ويدعم تعدد الخدمات والطلبات غير المدرجة.
- ملخص للطلب قابل لمراجعة وتعديل الإجابات.
- تجهيز رسالة واتساب للرقم `+967782021367`.
- أزرار الاتصال والبريد وروابط الحسابات الاجتماعية بالمعرّف `bsmtktab1`.
- تصميم Mobile First، قائمة هاتف، زر طلب ثابت للهاتف، وملفات PWA للعمل دون اتصال بعد أول زيارة على HTTPS.

## حدود المساعد والبيانات

المساعد لا يستخدم نموذج ChatGPT أو أي API خارجي. يعمل بقواعد محلية وكلمات مفتاحية وأسئلة توضيحية مخصصة للخدمات. يستطيع فهم بعض الأوصاف الدارجة والشائعة، لكنه لا يضمن فهم كل لهجة أو تعبير غير متوقع. عند عدم وضوح الطلب، يطلب توضيحاً أو يتيح اختيار خدمة يدوياً أو تسجيل طلب غير مدرج.

لا يرفع الموقع الملفات ولا يخزن طلبات العملاء على خادم. إجابات العميل تبقى في ذاكرة الصفحة أثناء الجلسة فقط، وتُمسح عند تحديث الصفحة أو إغلاقها. بعد تجهيز الرسالة، يفتح واتساب؛ وعلى العميل ضغط زر الإرسال بنفسه ثم إرفاق ملفاته في المحادثة.

## النشر

راجع `DEPLOY-CLOUDFLARE.md` لخطوات نشر الموقع مجاناً على Cloudflare Pages عبر الرفع المباشر.

## قبل الإعلان عن الموقع

- تأكد من فتح حسابات التواصل الخمسة على المعرّف `bsmtktab1`، وعدّل الروابط إذا اختلف اسم المستخدم في أي منصة.
- راجع الألوان النهائية إذا توفر ملف شعار متجهي أصلي.
- اختبر الموقع على أجهزة فعلية واتصال إنترنت متوسط، وتأكد من عمل روابط واتساب والاتصال والبريد.
